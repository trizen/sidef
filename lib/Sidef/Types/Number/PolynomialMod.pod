=encoding utf8

=head1 NAME

Sidef::Types::Number::PolynomialMod - Polynomial type over finite rings with modular arithmetic operations.

=head1 DESCRIPTION

This class implements polynomial arithmetic in quotient rings of the form R[x]/(m(x)), where polynomials are reduced modulo a fixed modulus polynomial C<m(x)>. This mirrors how integers modulo n work (via C<Sidef::Types::Number::Mod>), but in the polynomial domain.

A C<PolynomialMod> object is a pair C<[poly, modulus]> where C<poly> is the residue polynomial (already reduced) and C<modulus> is the polynomial by which all results are reduced. All arithmetic operations automatically reduce their result modulo the shared modulus.

Although a C<PolynomialMod> is internally stored as this C<[poly, modulus]> pair rather than the coefficient hash used by the parent L<Sidef::Types::Number::Polynomial> class, hash-style access such as C<$obj->{exponent}> is transparently redirected to the underlying residue polynomial's own storage. This is what lets many methods inherited unchanged from C<Polynomial> (like L</to_n> below) keep working correctly without needing to be reimplemented here.

Typical use cases include:

=over 4

=item * Finite field arithmetic (e.g., GF(2^8) for AES)

=item * Algebraic number fields (e.g., Q[x]/(x^2+1) ≅ Gaussian integers)

=item * Cyclotomic fields and rings of algebraic integers

=item * Factoring polynomials over finite fields

=back

=head1 SYNOPSIS

    # Create polynomials mod (1 + x^2) — working in Q[x]/(x^2 + 1)
    var i = PolynomialMod([0, 1], [1, 0, 1])   # represents the element x (i.e. sqrt(-1))
    say i**2     # Output: -1 (mod x^2 + 1)
    say i**4     # Output: 1 (mod x^2 + 1)

    # General arithmetic
    var p = PolynomialMod([1, 2, 3], [1, 0, 1])   # (3x^2 + 2x + 1) mod (x^2 + 1)
    var q = PolynomialMod([1, 2],   [1, 0, 1])    # (2x + 1) mod (x^2 + 1)
    say (p + q)      # Addition
    say (p - q)      # Subtraction
    say (p * q)      # Multiplication, reduced mod (x^2 + 1)
    say (p ** 3)     # Exponentiation via square-and-multiply

    # Division (exact when the inverse exists)
    say (p / q)

    # Polynomial GCD and extended GCD
    var (g, u, v) = p.gcdext(q)

    # Evaluate the polynomial at a point
    say p.eval(2)

    # Retrieve parts
    say p.modulus      # The modulus polynomial: x^2 + 1
    say p.to_poly      # The underlying Polynomial (without modulus)

    # CRT reconstruction (called as an instance method on one of the polynomials)
    var r = p.chinese(q)

=head1 COEFFICIENT ORDER IN ARRAY CONSTRUCTORS

When constructing from an array, coefficients are given in B<descending> degree order (highest-degree coefficient first):

    PolynomialMod([a_n, a_{n-1}, ..., a_1, a_0], modulus)
    # represents a_n*x^n + a_{n-1}*x^{n-1} + ... + a_1*x + a_0

Examples:

    PolynomialMod([1, 0, 1], [1, 0, 0, 1])
    # polynomial:  x^2 + 1
    # modulus:     x^3 + 1

    PolynomialMod([0, 1], [1, 0, 1])
    # polynomial:  x
    # modulus:     x^2 + 1

The same descending convention applies when constructing the modulus array.

=head1 INHERITS

Inherits methods from L<Sidef::Types::Number::Polynomial>.

Many methods not overridden here (such as C<degree>, C<coeffs>, C<exponents>, C<content>, C<leading_coefficient>, C<height>, etc.) are provided by the parent class and operate on the residue polynomial without further modulus reduction, thanks to the hash-access redirection described above.

=head1 CONSTRUCTION

=head2 new

    PolynomialMod(array_ref, modulus_array_ref)
    PolynomialMod(array_ref, modulus_poly)
    PolynomialMod(poly,      modulus)
    self.new(...)

Constructs a new C<PolynomialMod> object. The last argument is always the modulus; everything before it specifies the polynomial residue.

The modulus may be given as an array reference or as an existing C<Sidef::Types::Number::Polynomial> object. The residue polynomial is reduced modulo the modulus upon construction.

    # From coefficient arrays (descending degree order)
    var p = PolynomialMod([3, 2, 1], [1, 0, 1])   # (3x^2 + 2x + 1) mod (x^2 + 1)

    # From an existing Polynomial object
    var m = Polynomial([1, 0, 1])
    var p = PolynomialMod([3, 2, 1], m)

    # Instance-method form (creates new object with same class)
    var q = p.new([1, 2], [1, 0, 1])

B<Special case — instance call with one argument:> when called as an instance method with a single argument (no coefficients before the modulus), it evaluates the polynomial at that argument rather than constructing a new object. See L</eval>.

Aliases: I<call>

=cut

=head2 with_value

    self.with_value(value)

Creates a new B<constant> PolynomialMod holding just C<value>, in the same quotient ring as the receiver (same modulus). Discards the receiver's own residue polynomial entirely.

    var p = PolynomialMod([1, 2, 3], [1, 0, 1])
    say p.with_value(7)     # 7 (mod x^2 + 1)

=cut

=head1 COMPONENTS

=head2 to_poly

    self.to_poly

Returns the underlying C<Sidef::Types::Number::Polynomial> object, i.e. the reduced residue polynomial stripped of its modulus.

    var p = PolynomialMod([1, 2, 3], [1, 0, 1])
    say p.to_poly    # the residue polynomial, without a modulus

Aliases: I<lift>

=cut

=head2 modulus

    self.modulus

Returns the modulus polynomial by which all arithmetic in this quotient ring is reduced. The return value is a C<Sidef::Types::Number::Polynomial>.

    var p = PolynomialMod([1, 2], [1, 0, 1])
    say p.modulus   # x^2 + 1

=cut

=head1 ARITHMETIC OPERATIONS

=head2 add

    a + b

Returns the sum of C<a> and C<b>, reduced modulo the shared modulus. Both operands must share the same modulus polynomial. If C<b> is a scalar (non-PolynomialMod), it is added to the constant term after reduction.

Aliases: I<+>

=cut

=head2 sub

    a - b

Returns the difference C<a - b>, reduced modulo the shared modulus. If C<b> is a scalar, it is subtracted from the constant term after reduction.

Aliases: I<->

=cut

=head2 mul

    a * b

Returns the product of C<a> and C<b>, reduced modulo the shared modulus. Coefficient multiplication is also reduced modulo the modulus at each step, keeping intermediate values small.

If C<b> is a scalar, each coefficient of C<a> is multiplied by C<b> (after reducing C<b> mod the modulus) without a full polynomial multiplication.

Aliases: I<*>

=cut

=head2 sqr

    x.sqr

Returns the square of C<x> modulo the modulus. Equivalent to C<x * x>.

=cut

=head2 pow

    a ** n

Returns C<a> raised to the integer power C<n>, computed modulo the modulus polynomial using the binary (square-and-multiply) method. C<n> may be:

=over 4

=item * A non-negative integer — standard modular exponentiation.

=item * A negative integer — computes C<(a^|n|)^{-1}> via L</inv>.

=back

    var i = PolynomialMod([1, 0], [1, 0, 1])   # x mod (x^2 + 1)
    say i**2    # -1 mod (x^2 + 1)
    say i**4    #  1 mod (x^2 + 1)

Aliases: I<**>

=cut

=head2 powmod

    base.powmod(exp, poly_mod)

Computes C<base^exp mod poly_mod> using binary (square-and-multiply), reducing modulo C<poly_mod> after every multiplication to keep the degree below C<deg(poly_mod)>.

Returns a C<PolynomialMod> object, representing the modular exponentiation result.

=cut

=head2 div

    a / b

Divides C<a> by C<b> in the quotient ring.

=over 4

=item * If C<b> is a C<PolynomialMod> with the same modulus, polynomial Euclidean division is attempted. If the division is exact, the quotient is returned. If not exact, a C<Sidef::Types::Number::Fraction> object is returned.

=item * If C<b> is zero, returns a polynomial with an infinite coefficient.

=item * If C<b> is a scalar, each coefficient of C<a> is divided by C<b> (after reducing C<b> mod the modulus).

=back

Note that exact division in a polynomial quotient ring requires the leading coefficient of C<b> to be invertible modulo the coefficient ring (e.g., the modulus is prime for GF(p)[x] arithmetic). If the inverse does not exist (e.g. working over a non-field), the result is NaN.

Aliases: I<÷>

=cut

=head2 idiv

    a // b

Returns the integer quotient from Euclidean division of C<a> by C<b>, discarding the remainder. Equivalent to the quotient component of L</divmod>.

Note: The rounding variants (C<idiv_ceil>, C<idiv_floor>, C<idiv_round>, C<idiv_trunc>) are all currently aliased to the same integer-quotient behaviour.

Aliases: I<//>, I<idiv_ceil>, I<idiv_floor>, I<idiv_round>, I<idiv_trunc>

=cut

=head2 mod

    a % b

When C<b> is a C<PolynomialMod> with the B<same> modulus as C<a>, returns the remainder from Euclidean polynomial division (i.e. the second component of L</divmod>).

When C<b> is a different polynomial (or has a different modulus), B<reinterprets> C<b> as the new modulus and returns a new C<PolynomialMod> object with the same residue polynomial but reduced under the new modulus. This is the primary way to change the modulus of an existing polynomial.

    var p = PolynomialMod([1, 2, 3], [1, 0, 1])
    var q = PolynomialMod([1, 1],   [1, 0, 1])
    say (p % q)      # remainder of p divided by q, mod (x^2 + 1)

Aliases: I<%>

=cut

=head2 divmod

    x.divmod(y)

Performs Euclidean polynomial division of C<x> by C<y> within the quotient ring, using the standard long-division algorithm. The leading coefficient of C<y> must be invertible in the coefficient ring (its modular inverse is computed and used at each step).

Returns a list of two C<PolynomialMod> objects C<(quotient, remainder)> satisfying C<x == quotient * y + remainder> with C<deg(remainder) < deg(y)>.

If C<x> and C<y> have different moduli, both quotient and remainder are NaN. If the leading coefficient of C<y> has no modular inverse, returns NaN.

=cut

=head2 neg

    x.neg

Returns the additive inverse of C<x>: the polynomial whose coefficients are all negated. Adding C<x> and C<x.neg> yields the zero polynomial.

=cut

=head2 abs

    x.abs

Returns C<x> multiplied by the sign of its leading coefficient, ensuring the leading coefficient is positive. Equivalent to C<x * x.sgn>.

=cut

=head2 inc

    ++a

Increments C<a> by 1 (adds the constant polynomial 1) and reduces modulo the modulus. Equivalent to C<a + 1>.

Aliases: I<++>

=cut

=head2 dec

    --a

Decrements C<a> by 1 (subtracts the constant polynomial 1) and reduces modulo the modulus.

Aliases: I<-->

=cut

=head2 inv

    x.inv

Computes the multiplicative inverse of a PolynomialMod element.

In the quotient ring C<R[x]/(m(x))>, the inverse of C<f(x)> exists if and only if C<gcd(f, m) = 1>. When it exists, the extended Euclidean algorithm gives polynomials C<u> and C<v> such that:

  u(x)*f(x) + v(x)*m(x) = 1

which means C<u(x)*f(x) ≡ 1 (mod m(x))>, so C<u> is the inverse.

This uses C<Polynomial::gcdext> on the I<lifted> polynomials (plain polynomial ring arithmetic), which normalizes the GCD to monic. If the result is the constant polynomial C<1>, the Bézout coefficient C<u> is the inverse. The C<PolynomialMod> constructor automatically reduces C<u> modulo C<m>.

    # Matches PARI/GP: Mod(1+2*x, x^3+1)^(-1)
    var p = PolynomialMod([2, 1], [1, 0, 0, 1])   # (2x+1) mod (x^3+1)
    say(p.inv)    # -4/7*x^2 + 2/7*x - 1/7  (mod x^3+1)
    say((p * p.inv) == 1)   # true

=cut

=head1 GCD, LCM, AND FACTORIZATION

=head2 gcd

    x.gcd(y)

Returns the greatest common divisor of polynomials C<x> and C<y> in the quotient ring, using the polynomial Euclidean algorithm (repeated remainder computation):

    r0 = x, r1 = y
    loop: (r0, r1) = (r1, r0 mod r1) until r1 is zero
    return r0

Both C<x> and C<y> must share the same modulus. The result is the GCD as a C<PolynomialMod> in the same ring.

=cut

=head2 gcdext

    x.gcdext(y)

Extended Euclidean algorithm for polynomials in the quotient ring. Returns a list of B<five> values:

    (g, u, v, a1, b1)

where C<g = gcd(x, y)> and C<u>, C<v> are Bézout coefficients satisfying:

    u*x + v*y == g

The additional values C<a1> and C<b1> (the final remainders scaled by a sign factor) are also returned; they relate to the last non-trivial step of the extended Euclidean recursion.

    var (g, u, v) = p.gcdext(q)
    say ((u*p + v*q) == g)    # true

=cut

=head2 lcm

    x.lcm(y)

Returns the least common multiple of polynomials C<x> and C<y>, computed as:

    lcm(x, y) = abs(x * y) / gcd(x, y)

=cut

=head2 normalize_to_monic

    x.normalize_to_monic

Returns a monic version of C<x> (leading coefficient equal to 1) by multiplying each coefficient by the modular inverse of the leading coefficient. If the leading coefficient is already 1, C<x> is returned unchanged. If the inverse does not exist (e.g. the coefficient ring is not a field), returns C<x> unchanged.

=cut

=head2 factor_exp

    poly.factor_exp

Performs complete Cantor-Zassenhaus factorization of a polynomial over C<GF(p)[x]>.

B<Requirement:> this only works when the object's modulus is a plain prime B<number> (i.e., the polynomial represents an element of Z_p[x] directly), not a polynomial modulus — the more general C<R[x]/(m(x))> case used elsewhere in this class does not apply here.

The result includes multiplicities and is returned as an array of C<[factor, exponent]> pairs.

Each irreducible factor is returned as a monic C<PolynomialMod> object with scalar modulus C<p>. The first entry in the result is the leading coefficient of the original polynomial, represented as a C<[lc, 1]> pair.

B<Algorithm:>

=over 4

=item 1. B<Preprocessing> — the polynomial is normalized to monic form, then made squarefree by dividing by C<gcd(f, f')>. This removes one copy of each repeated factor.

=item 2. B<DDF> — Distinct Degree Factorization groups irreducible factors by degree.

=item 3. B<EDF> — Each DDF group is split into irreducible factors using Cantor-Zassenhaus.

=item 4. B<Multiplicity recovery> — each irreducible factor is repeatedly divided into the original polynomial to determine its multiplicity.

=back

=cut

=head2 factor

    poly.factor

Returns the factorization from L</factor_exp> as a flat array of factors, with each irreducible factor repeated according to its multiplicity. Subject to the same scalar-modulus requirement as L</factor_exp>.

=cut

=head1 CALCULUS

=head2 derivative

    x.derivative

Returns the formal derivative of C<x> with respect to the polynomial variable, reduced modulo the modulus. Each term C<c_k * t^k> maps to C<k * c_k * t^{k-1}>, with the coefficient also reduced modulo the modulus polynomial.

    var p = PolynomialMod([1, 3, 1], [1, 0, 1])   # x^2 + 3x + 1 mod (x^2+1)
    say p.derivative   # 3 + 2x, reduced mod (x^2 + 1)

=cut

=head2 eval

    x.eval(value)

Evaluates the polynomial at C<value>: C<value> is first reduced modulo the modulus, then each nonzero term C<coeff_k * value^k> is computed independently — with C<value^k> computed via modular exponentiation on C<Sidef::Types::Number::Mod> — and all the terms are summed and reduced modulo the modulus.

Returns a scalar (C<Sidef::Types::Number::Number>).

    var p = PolynomialMod([1, 2, 3], [1, 0, 1])
    say p.eval(2)     # sum of coeff_k * 2^k, reduced mod (x^2+1)

If the polynomial is the zero polynomial, returns 0 directly.

=cut

=head1 COMBINATORICS

=head2 binomial

    n.binomial(k)

Computes the generalised binomial coefficient C(n, k) where C<n> is a C<PolynomialMod> and C<k> is an integer. Uses the falling-factorial definition:

    C(n, k) = n * (n-1) * ... * (n-k+1) / k!

The product is computed via binary splitting for efficiency, and the division by C<k!> is performed via L</div>.

    var x = PolynomialMod([1, 0], [1, 0, 1])   # x mod (x^2+1)
    say x.binomial(2)   # x*(x-1)/2 mod (x^2+1)

=cut

=head1 CHINESE REMAINDER THEOREM

=head2 chinese

    self.chinese(other, ...)

Applies the Chinese Remainder Theorem (CRT) to the receiver together with one or more other C<PolynomialMod> objects that may have different moduli. Finds a single polynomial congruent to each one modulo its own modulus. The combined modulus is the LCM of all the individual moduli.

Called as an B<instance method> on one of the polynomials being combined — not as a class-level call:

    var a = PolynomialMod([1, 2], [1, 0, 1])   # 2x+1 mod (x^2+1)
    var b = PolynomialMod([3, 1], [1, 1, 1])   # x+3 mod (x^2+x+1)
    var c = a.chinese(b)

=cut

=head1 COMPARISON

=head2 eq

    a == b

Returns true if C<a> and C<b> are equal as elements of the same quotient ring. Two C<PolynomialMod> objects are equal if and only if their moduli are equal and their residue polynomials are equal (coefficient by coefficient). When comparing against a non-C<PolynomialMod> value, the value is reduced modulo C<a>'s modulus before comparison.

Aliases: I<==>

=cut

=head2 ne

    a != b

Returns true if C<a> is not equal to C<b>. Implemented as the logical negation of L</eq>.

Aliases: I<!=>

=cut

=head2 cmp

    a <=> b

Three-way comparison. When both arguments are C<PolynomialMod> objects, the moduli are compared first; if they differ, that result is returned. Otherwise the residue polynomials are compared lexicographically (highest-degree coefficient first, then lower degrees). Returns -1, 0, or 1.

Aliases: I<<< <=> >>>

=cut

=head2 gt

=head2 le

=head2 __boolify__

    self.__boolify__

Backs the object's boolean-context overload (e.g. C<if polymod_value>). Checks only the constant term (coefficient of x^0) of the residue polynomial: truthy if it's present and nonzero, falsy if it's zero or absent — regardless of whether other, higher-degree terms are nonzero.

    if (PolynomialMod([1, 0], [1, 0, 1])) { ... }   # falsy: no constant term
    if (PolynomialMod([1, 3], [1, 0, 1])) { ... }   # truthy: constant term is 3

=cut

=head1 EXAMPLES

=head2 Gaussian integers via Q[x]/(x² + 1)

    var i = PolynomialMod([1, 0], [1, 0, 1])   # x ≡ i
    say i**2    # -1 (mod x^2 + 1)
    say i**4    # 1  (mod x^2 + 1)

    var a = PolynomialMod([3, 2], [1, 0, 1])   # 2x + 3 ≡ 3 + 2i
    var b = PolynomialMod([1, 4], [1, 0, 1])   # 4x + 1 ≡ 1 + 4i
    say (a * b)   # (3+2i)(1+4i) = 3+12i+2i+8i^2 = (3-8) + 14i = -5 + 14i
                  # Output: 14*x - 5 (mod x^2 + 1)

=head2 GCD and Bézout coefficients

    var p = PolynomialMod([1, 0, 1], [1, 0, 0, 1])  # x^2+1 mod x^3+1
    var q = PolynomialMod([1, 1],   [1, 0, 0, 1])   # x+1   mod x^3+1
    var (g, u, v) = p.gcdext(q)
    say g             # gcd
    say (u*p + v*q)   # should equal g

=head2 Finite field GF(2)[x]/(x^4 + x + 1) — an irreducible polynomial over GF(2)

    var m = [1, 0, 0, 1, 1]    # x^4 + x + 1
    var a = PolynomialMod([1, 1, 0, 1], m)  # x^3 + x + 1
    var b = PolynomialMod([1, 0, 1, 1], m)  # x^3 + x^2 + 1
    say (a * b)    # product in GF(2^4)

=head2 Chinese Remainder Theorem

    var a = PolynomialMod([2, 1], [1, 0, 1])   # 2x+1 mod (x^2+1)
    var b = PolynomialMod([1, 3], [1, 1, 1])   # x+3  mod (x^2+x+1)
    var c = a.chinese(b)
    say c         # polynomial congruent to both a and b mod their respective moduli

=head2 Derivative in a quotient ring

    var p = PolynomialMod([1, 0, 3, 2], [1, 0, 1])  # 3x^2 + 2x (after reduction)
    say p.derivative   # formal derivative reduced mod (x^2 + 1)

=head2 Factoring over GF(p)[x]

    # Modulus here is the scalar prime p, not a polynomial
    var f = PolynomialMod([1, 0, -1], 5)   # x^2 - 1 over GF(5)
    say f.factor_exp
    say f.factor

=head1 NOTES

=over 4

=item *

B<Operand compatibility:> Most binary operations (C<+>, C<->, C<*>, C<gcd>, C<divmod>, etc.) require both operands to share the same modulus polynomial. Mixing operands with different moduli will either give wrong results or return NaN.

=item *

B<Coefficient ring:> Coefficients are general C<Sidef::Types::Number::Number> objects (arbitrary precision). For finite-field semantics (e.g. GF(p)[x]), you should use a modulus polynomial whose coefficients are already in GF(p) and ensure your input coefficients are also reduced mod p.

=back
