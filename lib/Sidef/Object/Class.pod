=encoding utf8

=head1 NAME

Sidef::Object::Class - The run-time support of the Sidef classes

=head1 DESCRIPTION

The code generated by L<Sidef::Deparse::Perl> declares every Sidef class with a call of C<declare()>.
This module implements what a class does: the inheritance, the construction of the objects and the accessors.

=head2 Declarations

Every C<class> statement is a I<declaration>. A class that is declared again is a new declaration, which
inherits from the previous one and lives in the same Perl package:

    class Foo(a) { ... }
    class Foo(b) { ... }     # Foo has now two fields: a and b

=head2 Inheritance

The declarations are linearized with C3 (the most derived first). The same order is used for the Perl C<@ISA>
(C<mro 'c3'>), therefore the methods are resolved as the fields are:

    class Left  < Base { }
    class Right < Base { }
    class Both  < Left, Right { }       # Both, Left, Right, Base

The base class of all the objects (C<Sidef::Object::Object>) is always the last one.

=head2 Fields

A field is I<owned> by the first declaration that declares it (in the C3 order), whether it declares the field
as a parameter of the constructor or as an attribute (C<has>). In other words, the most derived declaration wins:

    class A(x = 1, y = 2) { }
    class B(x = 10) < A { }             # the default value of `x` is 10
    class C < B { has y = 5 }           # `y` is an attribute now, not a parameter

The fields are visible in the methods by their names, including the inherited ones.

=head2 The constructor

The parameters of the constructor are the fields that are declared as parameters by their owners.
The inherited parameters come first (the parents from left to right), followed by the parameters
of the class itself. A parameter that is declared again, takes the position of the new declaration.
Parameters can be given by position or by name.

A slurpy parameter (C<*args>, C<:opts>) must be the last parameter of the constructor, including the inherited ones.

An object is created in four steps:

=over 4

=item 1.

the arguments are bound to the parameters, and their types are checked;

=item 2.

the default values of the parameters are evaluated (the most derived class first);

=item 3.

the attributes are evaluated (the most derived class first). An attribute that is overridden by a more derived class is not evaluated;

=item 4.

the C<init> method is called, if there is one.

=back

=head1 METHODS

=head2 declare

    Sidef::Object::Class->declare(%declaration);

Declares a class and installs its constructor (C<new> and C<call>), its accessors and its C<@ISA>.
Returns the declaration. See L<Sidef::Deparse::Perl> for the options.

=head2 extend

    Sidef::Object::Class->extend($package, @parents);

Adds parents to a built-in class (C<class String << Custom { ... }>).

=head2 lookup

    my $declaration = Sidef::Object::Class->lookup($key);

Returns a declaration from the registry.

=head2 linearize

    my @declarations = $declaration->linearize;

Returns the declarations in the C3 order.

=head2 instantiate

    my $object = $declaration->instantiate(@arguments);

Creates an object. The arguments are the values of the parameters, in order.

=head1 SEE ALSO

L<Sidef::Deparse::Perl>, L<Sidef::Types::Block::Block>

=cut
